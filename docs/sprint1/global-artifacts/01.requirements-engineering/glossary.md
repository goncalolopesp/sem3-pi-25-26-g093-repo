# Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**


Here’s the table sorted alphabetically:

| ***TEA*** (EN)                      | ***TEA*** (PT)                                | ***Description*** (EN)                                                                                             |
|:------------------------------------|:----------------------------------------------|:-------------------------------------------------------------------------------------------------------------------|
| **ARQCP**                           | **ARQCP**                                     | Curricular unit *Computer Architecture* (Arquitetura de Computadores).                                             |
| **Aisle**                           | **Corredor**                                  | Path within a warehouse, containing several bays for storage.                                                      |
| **Backlog**                         | **Backlog**                                   | Prioritized list of requirements and tasks to be implemented in the project.                                       |
| **Bay**                             | **Baia**                                      | Storage unit inside a warehouse, with defined capacity for product boxes.                                          |
| **BDDAD**                           | **BDDAD**                                     | Curricular unit *Databases* (Bases de Dados).                                                                      |
| **Box Car**                         | **Vagão Fechado**                             | Wagon used for general goods transport.                                                                            |
| **Station Master**                  | **Chefe de Estação**                          | User responsible for coordinating arrivals and departures at a station.                                            |
| **CSV File**                        | **Ficheiro CSV**                              | Comma-separated values file used for data exchange (e.g., wagons.csv, orders.csv).                                 |
| **ESINF**                           | **ESINF**                                     | Curricular unit *Information Structures* (Estruturas de Informação).                                               |
| **FEFO (First Expired, First Out)** | **PVPS (Primeiro a Vencer, Primeiro a Sair)** | Stock rotation principle prioritizing products with the earliest expiry dates.                                     |
| **FIFO (First In, First Out)**      | **PEPS (Primeiro a Entrar, Primeiro a Sair)** | Inventory management principle where older products are dispatched before newer ones.                              |
| **Flat Car**                        | **Vagão Plataforma**                          | Wagon used for containers, vehicles, and large machinery.                                                          |
| **Freight Manager**                 | **Gestor de Cargas**                          | User responsible for cargo allocation, monitoring, and logistics management.                                       |
| **Freight Yard**                    | **Pátio de Manobras**                         | An area for assembling, disassembling, and storing trains and wagons.                                              |
| **FSIAP**                           | **FSIAP**                                     | Curricular unit *Applied Physics* (Física Aplicada).                                                               |
| **Gauge**                           | **Bitola**                                    | The distance between the two rails of a track, defining train compatibility.                                       |
| **LAPR3**                           | **LAPR3**                                     | Curricular unit *Laboratory-Project III* (Laboratório de Projeto III).                                             |
| **Line Segment**                    | **Segmento de Linha**                         | A portion of a railway line with its own characteristics, such as length, gauge, electrification, and speed limit. |
| **Locomotive**                      | **Locomotiva**                                | Engine vehicle that provides power to move trains along tracks.                                                    |
| **Oracle LiveSQL**                  | **Oracle LiveSQL**                            | Online environment for executing and testing SQL code.                                                             |
| **Picking**                         | **Recolha de Produtos / Picking**             | The process of collecting products from storage locations to fulfill orders.                                       |
| **Picking Path**                    | **Percurso de Picking**                       | The optimized route to follow when collecting products in a warehouse.                                             |
| **Picking Plan**                    | **Plano de Picking**                          | Structured sequence for collecting items in a warehouse, considering location and trolley capacity.                |
| **Product Owner (PO)**              | **Proprietário do Produto (PO)**              | SCRUM role responsible for defining priorities and ensuring the product meets user needs.                          |
| **Railway Line**                    | **Linha Ferroviária**                         | A set of track segments connecting two or more stations or terminals.                                              |
| **Refrigerated Car**                | **Vagão Refrigerado**                         | Wagon with cooling systems for perishable goods.                                                                   |
| **Return (Quarantine)**             | **Devolução (Quarentena)**                    | Returned products stored temporarily until inspected and either discarded or restocked.                            |
| **Route / Itinerary**               | **Rota / Itinerário**                         | Ordered sequence of stations through which a train passes to travel from origin to destination.                    |
| **Scheduler / Planner**             | **Planeador**                                 | User responsible for defining train timetables and optimizing logistics operations.                                |
| **Scrum**                           | **Scrum**                                     | Agile project management framework based on iterative sprints.                                                     |
| **SKU (Stock Keeping Unit)**        | **Unidade de Manutenção de Stock (SKU)**      | Unique identifier for each product stored and tracked in logistics operations.                                     |
| **Sprint**                          | **Sprint**                                    | A fixed period (4 weeks in this project) in which a set of user stories is implemented.                            |
| **Station Storage Manager**         | **Gestor de Armazém da Estação**              | User responsible for warehouse and storage operations at a station.                                                |
| **Tank Car**                        | **Vagão-Tanque**                              | Wagon designed for transporting liquids, chemicals, or fuels.                                                      |
| **Terminal**                        | **Terminal**                                  | A logistics hub where trains are loaded/unloaded, often with warehouses and intermodal facilities.                 |
| **TDD (Test-Driven Development)**   | **TDD (Desenvolvimento Orientado a Testes)**  | Software development approach where tests are written before code implementation.                                  |
| **Trolley**                         | **Carro de Picking**                          | A cart used by warehouse workers to collect and transport items, with a maximum weight capacity.                   |
| **Visual Paradigm**                 | **Visual Paradigm**                           | A modeling tool used for conceptual and relational data models.                                                    |
| **Wagon (Freight Car)**             | **Vagão**                                     | A railway vehicle designed to carry goods (e.g., tank cars, boxcars, flatcars).                                    |
| **Warehouse**                       | **Armazém**                                   | Facility for storing goods, organized in aisles and bays.                                                          |
