# USBD35 – Register a new facility

## Description
This user story allows the registration of a new facility in the database,
validating the existence of the facility type.

## Files
- USBD35_Function.sql – PL/SQL function implementation
- USBD35_UnitTests.sql – Unit tests
- USBD35_CleanUp.sql – Clean up script

## Notes
The function returns TRUE if the facility is successfully created,
or FALSE otherwise.
