# USBD003 – Instantiate the Relational Model (SQL DDL)

## 1. Requirements Engineering

### 1.1. User Story Description
As a Product Owner, I want the relational model to be instantiated using SQL DDL code generated by Visual Paradigm.

### 1.2. Customer Specifications and Clarifications

**From the specifications document:**
* The database schema must be deployed on Oracle LiveSQL.

**From the client clarifications:**
* SQL script must run without errors.
* No missing constraints (PK/FK/UNIQUE/CHECK/NOT NULL).

### 1.3. Acceptance Criteria

* **AC1:** DDL exported directly from Visual Paradigm.
* **AC2:** Execution on Oracle LiveSQL without warnings/errors.
* **AC3:** Naming conventions preserved.
* **AC4:** Appropriate data types and constraints applied.
* **AC5:** Schema ready to receive data from USBD004.

**Input Data:**
* SQL DDL script auto-generated by VP

**Output Data:**
